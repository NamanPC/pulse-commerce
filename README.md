# PulseCommerce - Enterprise E-Commerce Platform

PulseCommerce is a full-stack e-commerce and billing platform built with Express, React, and PostgreSQL.

## Architecture Overview
- `client/`: Single Page Application (React / Vite)
- `server/`: RESTful Backend API (Node.js / Express)
- `database/`: Schema migrations and seeders
- `docker-compose.yml`: Multi-container local orchestration

## Getting Started
See server and client subdirectories for installation instructions.
